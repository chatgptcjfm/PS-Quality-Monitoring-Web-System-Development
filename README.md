# Quality Ledger

## 프로젝트 개요
엑셀 `변경일지` 데이터를 업로드해 품질 측정값을 시각화하고 규격 이탈을 빠르게 확인하는 Cloudflare Pages용 품질 분석 프리뷰입니다.

## 구현 기능
- `.xls` / `.xlsx` 드래그 앤 드롭 업로드 및 `변경일지` 시트 자동 인식
- `xlsx` 기반 브라우저 파일 파싱
- Recharts 시계열 트렌드 차트
- USL / LSL 입력과 규격 이탈 빨간색 강조
- 지종·측정항목 필터, 최근 관측 데이터 테이블
- lucide-react 아이콘 기반 대시보드 UI

## 실행
```bash
npm install
npm run build
pm2 start ecosystem.config.cjs
```

프리뷰는 `http://localhost:3000`에서 확인합니다.

## 데이터 규칙
- 변경일지의 9행부터 측정 데이터로 읽습니다.
- 지종 대분류(열 G)와 평량 중분류(열 H)를 별도 필터로 제공합니다.
- 평량·두께·수분·백색도·PPS는 전/중/후 위치값을 분리 표시하고 위치 평균을 계산합니다.
- TV15는 인쇄층분리, TV20은 픽킹으로 표시하며, 내절도는 0.7 탭을 사용하고 MD/CD 슬래시 값을 평균합니다.
- 스티프니스는 MD/CD, 인터널은 슬래시 포함 숫자 평균, 파열강도·모틀링은 단일 측정값으로 매핑합니다.
- 기본 평량 규격은 USL 306, LSL 294이며 품질 항목 변경 시 해당 기본 규격으로 전환됩니다.
- 실제 운영 데이터 저장소는 사용하지 않으며, 업로드된 파일은 브라우저에서만 처리합니다.
