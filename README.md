# Quality Ledger

## 프로젝트 개요
엑셀 `변경일지` 데이터를 업로드해 품질 측정값을 시각화하고 규격 이탈을 빠르게 확인하는 Cloudflare Pages용 품질 분석 프리뷰입니다.

## 구현 기능
- `.xls` / `.xlsx` 드래그 앤 드롭 업로드 및 모든 유효한 탭 자동 분석
- `xlsx` 기반 브라우저 파일 파싱
- Recharts 시계열 트렌드 차트
- USL / LSL 입력과 규격 이탈 빨간색 강조
- 지종·측정항목 필터, 최근 관측 데이터 테이블
- lucide-react 아이콘 기반 대시보드 UI

## 실행
```bash
npm install
npm run build
pm2 start ecosystem.config.cjs
```

프리뷰는 `http://localhost:3000`에서 확인합니다.

## 데이터 규칙
- 업로드 파일의 모든 유효한 시트를 순회해 9행부터 측정 데이터로 읽습니다.
- 각 시트명에서 지종/평량을 추출합니다. 예: `IV300` → 지종 `IV`, 평량 `300`; `SC250(미국)` → 지종 `SC`, 평량 `250 (미국)`으로 별도 구분합니다.
- 화면 필터는 1행의 `시작일`·`종료일`, 2행의 `호기`·`지종`·`평량`·`품질 분류`·`품질 항목`으로 2줄 구성합니다. 호기는 업로드 파일명에 포함된 `2호기` 또는 `3호기`로만 분류합니다. 엑셀을 처음 불러온 뒤에는 모든 데이터 필터가 `선택 안 함` 상태로 시작해 대량 데이터가 즉시 렌더링되지 않습니다. 선택한 호기와 지종에 실제 존재하는 평량만 평량 목록에 표시합니다.
- 생산 시각은 엑셀의 월·일·시·분 열을 조합해 표시하고, 거래처(항차번호) 열의 `1월`~`12월` 월 구분 항목과 거래처 값이 없는 헤더/행은 데이터에서 제외합니다. `6810J30061` 롤까지 포함한 뒤 이후 행은 매핑하지 않습니다.
- 시작일·종료일 기간 필터로 데이터를 제한할 수 있으며, 생산 시각 기준으로 트렌드·평균·상세표에 함께 적용됩니다. 여러 엑셀 파일을 선택하거나 드래그 앤 드롭하면 기존 데이터에 누적됩니다. 업로드 중복 파일은 데이터 중복을 방지하면서도 업로드 파일명 목록에는 전체 표시됩니다.
- 빈 측정값은 트렌드 그래프와 평균 계산에서 제외합니다.
- 트렌드 그래프 Y축은 선택 품질항목의 실제 최소·최대값과 표준편차(6시그마)를 계산하고 USL/LSL을 함께 반영해 품질항목별 편차와 변화가 보이도록 유동적으로 자동 조정합니다. Y축 눈금은 소수점 한 자리로 표시합니다.
- 평량·두께·수분·PPS·백색도 표면·뒤비침은 전/중/후, 단일 항목은 단일값으로 표시합니다.
- PPS는 표면 전/중/후만 사용하며 후면은 제외하고, TV15는 인쇄층분리, TV20은 픽킹으로 표시합니다.
- 품질 분류는 물리적특성, 강도특성, 인쇄특성, 색상, 기타, 부착량으로 제공하며, 분류 선택 시 해당 품질 항목만 표시합니다. 밀도, 모틀링, 내절도 MD/CD, 스티프니스 MD/CD, 파열강도, 인터널을 매핑합니다.
- 내절도를 제외한 슬래시 숫자는 평균값으로 처리합니다.
- 부착량과 부착 백색도를 표면·이면·후이면·후면별로 제공합니다.
- 뒤비침 전/중/후, 표면·후면 색차 L/a/b, 후면지분, 금속 검출 MD/CD(20장 탭)를 품질 항목으로 제공합니다. 상세 측정 데이터 표에는 금속 MD/CD 별도 열을 표시하지 않습니다.
- 기본 평량 규격은 USL 306, LSL 294이며 품질 항목 변경 시 해당 기본 규격으로 전환됩니다.
- 실제 운영 데이터 저장소는 사용하지 않으며, 업로드된 파일은 브라우저에서만 처리합니다.
